# Skill: модельные персоны с маркировкой синтетики

## Когда использовать

Нужно понять, как запрос звучит для разных типов пользователя, но реальных
интервью нет. Применяется при сборке `personas.md`, **не** при выборе
контура.

## Что делать

1. **Определи 3–5 разных ролей** — не «все пользователи».
2. **Один открытый вопрос на роль**, без подсказки ответа.
3. **Получи ответы у модели**, задав ей роль респондента.
4. **Пометь каждое утверждение как синтетику.** Модельный ответ не
   доказывает спрос и не показывает распространённость потребности.
5. **Вынеси в гипотезы, не в факты.** Ни одно утверждение модельного
   респондента не становится фактом: у него нет источника.

## Чего нельзя

- Выдавать синтетические ответы за реальные интервью.
- Считать количество повторов подтверждением частоты мнения.
- Использовать ответы как основание для решения — только как указание, что
  стоит спросить у настоящих людей.

## Метрики / проверка

- Каждый ответ помечен как синтетический.
- В персоне нет утверждений из ответов респондентов без пометки.
- В открытых вопросах сказано, что реальных интервью не было.
