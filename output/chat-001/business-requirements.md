## Контур

B2B, Россия, русский язык, ₽; подписка SaaS за рабочее место. **[факт]** (ответ заказчика).

## AS-IS

Малые команды ведут продажи в Google Sheets/Excel + мессенджерах + почте + блокноте.
Сделки и история размазаны по каналам, руководитель не видит воронку, при уходе
менеджера теряется контекст. Существующие CRM (amoCRM, Bitrix24) воспринимаются
как перегруженные и дорогие для команд 2–20 **[гипотеза — требует проверки]**.

## TO-BE

Лёгкая B2B CRM для команд 2–20: единое место для контактов, сделок, переписок и
звонков; воронка, задачи, отчёты, автоматизация; быстрый старт (time-to-value
≤ 10 мин); дешевле и прозрачнее конкурентов; веб + PWA; интеграции почта +
мессенджеры + IP-телефония + платежи; соответствует 152-ФЗ.
Измеримые критерии — в «Критерии приёмки» ниже.

## Критерии приёмки

| ID | Критерий | Как проверить |
|---|---|---|
| AC-1 | За ≤10 мин от регистрации создана первая сделка и видна в воронке | телеметрия time-to-first-deal / юзер-тест |
| AC-2 | В карточке клиента видны контакты, сделки и история переписки/звонков | демо-сценарий |
| AC-3 | Руководитель видит отчёт по воронке и конверсии по этапам | демо-сценарий |
| AC-4 | Триггер «этап изменился → задача/уведомление» срабатывает | автотест |
| AC-5 | Автоцепочка сообщений по клиенту отправляется по расписанию | автотест |
| AC-6 | Интеграция (почта/мессенджер/телефония/платежи) подключается без разработчика | демо-сценарий |
| AC-7 | Приложение работает в браузере и как PWA на телефоне | ручная проверка |
| AC-8 | Тарифы прозрачны, оплата подписки проходит через платёжный шлюз РФ | демо + чек |
| AC-9 | ПДн хранятся в РФ, есть согласие и политика хранения | юридическая проверка |

## Варианты решения

| Вариант | Описание | Возражения (≥2) |
|---|---|---|
| Оставить как есть | Команды продолжают в таблицах + мессенджерах | (1) потери сделок и данных растут с ростом команды; (2) нет управляемости — руководитель не видит воронку |
| Закрыть направление | Не делать CRM, отдать рынок amoCRM/Bitrix24 | (1) существующие перегружены/дороги для 2–20 — ниша есть **[гипотеза]**; (2) отказ противоречит цели ARR 5–20 млн ₽/год |
| Основной | Лёгкая дешёвая B2B CRM для команд 2–20 с быстрым стартом и интеграциями | (1) ценовая конкуренция давит маржу — юнит-экономику надо подтвердить (Q-15); (2) полный scope за 6 мес / 5–15 млн ₽ — риск не уложиться, нужна жёсткая приоритизация MVP |

## Модель тарифов (предложение, требует валидации — Q-15)

**[предложение / прогноз]** — не факт. PM предлагает 3 тарифа за рабочее место/мес:
Старт (базовое), Рост (автоматизация + отчёты), Про (расширенные лимиты).
Проверка ARR-цели: при среднем чеке ~30–60 тыс ₽/год на компанию (5 мест)
цель 5–20 млн ₽/год = ~85–660 компаний-клиентов. Точные цены — на BA-gate.
