# Нефункциональные требования

| ID | Категория | Требование | Как проверяем |
|---|---|---|---|
| NFR-1 | производительность | p95 API < 300 мс на типовых операциях (контакт, сделка) | нагрузочный тест |
| NFR-2 | доступность | доступность 99.5% в месяц, RPO ≤ 15 мин | мониторинг SLA |
| NFR-3 | безопасность | шифрование данных at rest и in transit, RBAC | аудит безопасности |
| NFR-4 | данные | минимизация ПДн, срок хранения, право на удаление (152-ФЗ) | аудит ПДн |
| NFR-5 | локализация | RU по умолчанию, EN опционально | ревью локализации |
| NFR-6 | доступность (a11y) | базовое соответствие WCAG 2.1 AA | аудит доступности |
| NFR-7 | мобильность | PWA time-to-interactive < 3 с на 4G | Lighthouse mobile |
| NFR-8 | наблюдаемость | логи, метрики, алерты по ошибкам биллинга | ревью мониторинга |

## Категории

- производительность и latency;
- безопасность и доступ;
- доступность и отказоустойчивость;
- данные: персональные, хранение, минимизация;
- локализация, a11y, наблюдаемость.
