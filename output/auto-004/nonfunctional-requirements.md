# Нефункциональные требования

| ID | Категория | Требование | Мера / Порог | Метод проверки |
|---|---|---|---|---|
| NFR-1 | производительность | Проверка согласованности прогона не мешает работе | p95 <= 2 с на прогоне из 16 артефактов | замер 10 последовательных запусков |
| NFR-2 | детерминизм | Прогон без модели воспроизводим | 3 прогона из 3 совпадают, доля пройденных кейсов 100% | три повторных запуска eval-mock |
| NFR-3 | автономность | Проверки и mock не обращаются к сети | 0 сетевых запросов за прогон | запуск с отключённым сетевым интерфейсом |
| NFR-4 | переносимость | Поддержка Linux, macOS с GNU make, Windows через WSL2; Python 3.11+, Node 18+, mmdc >= 12.0.0 | setup зелёный на 3 платформах | make check-prereqs в матрице CI |
| NFR-5 | надёжность | Гейты падают громко: непустой список проблем даёт код 1, пустой список прогонов — ошибка | 100% контрактных тестов scripts | pytest-контракты в tests/ |
| NFR-6 | безопасность | В публикуемом контенте нет секретов и домашних путей | 0 находок сканера | make check-public |
| NFR-7 | приватность | Артефакты хранятся локально; внешняя LLM только по явному решению | 0 отправок данных по умолчанию | аудит конфигурации и ответ на Q-4 |
| NFR-8 | доступность | У каждой диаграммы есть текстовый источник; текст на PNG соответствует WCAG 2.1 AA | 100% диаграмм имеют .mmd; контраст текста >= 4.5:1 | аудит рендера и палитры mermaid-config.json |
| NFR-9 | сопровождаемость | Единый источник правды по ролям и скилам; добавление роли или скила не требует правки более одного реестра | check-sync зелёный | make check-sync |
| NFR-10 | локализация | Артефакты и сообщения CLI на русском, ID и команды латиницей, кодировка UTF-8 | 0 ошибок кодировки в скане | ревью артефактов и вывод CLI |

## Категории

- производительность и latency;
- безопасность и доступ;
- доступность и отказоустойчивость;
- данные: персональные, хранение, минимизация;
- локализация и регион.

## Что не задано

- Целевой uptime: серверной части нет, поэтому SLA не применим [факт:
  `docs/connect.md`].
- Целевое время полного прогона с моделью: зависит от модели и размера идеи,
  baseline не измерен [нет данных], см. FR-15.
