# Персоны

> Каждая персона — тот, у кого есть задача, которую решает продукт.
> Модельная персона помечается как синтетика.

| Персона | Роль | Контекст | Задача | Что мешает | Синтетика? |
|---|---|---|---|---|---|
| P-1 «Специалист по качеству каталога» | Основной пользователь | Принимает партии карточек от партнёров, следит за качеством каталога М.Видео | Проверять только сомнительные значения, а не всё вручную | Ручной перенос значений из описания в поля; нет цитаты-доказательства | нет (роль из CASE/MICROBRIEF) |
| P-2 «ML-инженер каталога» | Основной пользователь | Добавляет новые категории, смотрит метрики качества | Добавить категорию по конфигу схемы и сразу увидеть F1 | Новая категория = новая ручная работа над словарями | нет (роль из 01-product-context) |
| P-3 «Покупатель» | Выгодоприобретатель (транзитивно) | Ставит фильтры в поиске М.Видео | Найти все подходящие товары по фильтру (напр. «256 ГБ») | Товар не виден, потому что характеристика спрятана в тексте | нет (роль из CASE §2) |
| P-4 «Партнёр-продавец» | Выгодоприобретатель (транзитивно) | Загружает карточки в своём формате | Загрузить товар как есть и сразу попасть в фильтры | Приходится переписывать карточку под шаблон площадки | нет (роль из 04-value-economics) |

## Контур

B2B, Россия, RU/EN, внутренний инструмент каталога М.Видео + сервис для
партнёров. Монетизация в MVP не определена (**[допущение]**).
