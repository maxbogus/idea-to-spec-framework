## Вход

Сырая идея — хакатон «Точка сборки» 2026, задача №3 (кейсодатель М.Видео):
сервис автоматического заполнения характеристик товаров из текста карточки

## Что подтверждено

- Каталог 1,18M карточек / 31M кликов; top-5 ≈24% трафика. **[факт]**
- Hybrid F1 80.4% на слепом test (baseline 10.6%); precision «в карточку»
  96.5% при accept 66.8%. **[факт]**
- 48.9% описаний с HTML; 60% кликов без brand. **[факт]**
- p95 13.2 мс; peak RSS 1.04 ГБ. **[факт]**

## Что осталось допущением

- Порог автоприёма 0,85; цена LLM 0,5 ₽/вызов; модель монетизации;
  «карточки не персональные» (прямой проверки нет).

## Главный вывод прогона

На хорошо прописанном входе (хакатон с реальным бэкендом и EDA) авто-режим
даёт **заземлённые** артефакты: большинство чисел — подтверждённые факты из
источника, а не галлюцинации. Разрывы (порог, цена, монетизация) не
заполняются догадками, а явно помечаются как допущения и открытые вопросы.
