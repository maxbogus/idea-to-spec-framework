# Нефункциональные требования

| ID | Категория | Требование | Как проверяем |
|---|---|---|---|
| NFR-1 | производительность | Latency p95 ≤ 50 мс на карточку в hybrid без LLM (замерено 13.2 мс на ноутбуке) | `make test-perf`, логи latency_ms |
| NFR-2 | производительность / память | Peak RSS < 4 ГБ на batch (замерено 1.04 ГБ на 1.18M) | memory-замер batch-прогона |
| NFR-3 | безопасность | Защита от prompt injection, JSON-бомбы, ReDoS, XXE, формул CSV/XLSX | `make test-security` |
| NFR-4 | доступность | При недоступности LLM / Redis — деградация к ответу правил, а не ошибка | тесты resilience, integration |
| NFR-5 | данные | Карточки не персональные; source_span хранится для аудита; лишнего не храним | ревизия схемы БД |
| NFR-6 | локализация | Поддержка RU/EN значений и брендов (87.32% смешанных описаний) | unit-тесты токенизации/нормализации |

## Категории

- производительность и latency;
- безопасность и доступ;
- доступность и отказоустойчивость;
- данные: персональные, хранение, минимизация;
- локализация и регион.
