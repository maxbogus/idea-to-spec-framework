# Traceability Matrix

> Связь: бизнес-цель → требование → спецификация → критерий приёмки →
> тест/компонент → задача → коммит/тест → статус. Требование без адресата и
> без задачи — недозрелое.

| Бизнес-цель | Требование | Спецификация | Критерий приёмки | Тест / компонент | Задача (T-*) | Коммит / тест | Статус |
|---|---|---|---|---|---|---|---|
| G-1 | BR-1 | FR-1 | AC-1 |  | T-1 |  | draft |
| G-1 | BR-2 | NFR-1 | AC-2 |  | T-2 |  | draft |

> `Задача (T-*)` — идентификатор из плана Project Manager: по нему видно,
> какая работа закрывает требование. `Коммит / тест` — чем покрытие
> подтверждено; на этапе плана колонка может быть пустой, заполняется по мере
> реализации. `Статус` — состояние покрытия требования: `draft`, `approved`,
> `implemented`, `verified`, `superseded`. Требование без задачи и статуса не
> считается покрытым — `make check-run` фиксирует это как проблему.

## Проверка полноты

- [ ] у каждого требования есть бизнес-цель
- [ ] у каждого требования есть критерий приёмки
- [ ] у каждого требования есть адресат (компонент или тест)
- [ ] у каждого требования есть задача (`T-*`) и статус покрытия
