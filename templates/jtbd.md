# JTBD — Jobs To Be Done

> Работа, которую персона «нанимает» продукт выполнить. Отвечает на вопрос
> «зачем пользователю продукт» — до того, как появляются use cases.
> Строится из `personas.md`. Персона: **P-? «…»**.

## Job stories

Формат: «Когда <ситуация>, я хочу <мотивация>, чтобы <ожидаемый результат>».

| ID | Персона | Когда (ситуация) | Хочу (мотивация) | Чтобы (результат) | Тип: функц. / эмоц. / соц. |
|---|---|---|---|---|---|
| J-1 | P-? |  |  |  |  |

## Связь с требованиями

- Каждый `UC-*` в `use-cases.md` трассируется до `J-*` (или помечен как вне
  JTBD).
- JTBD — это работа, а не решение: «хочу быстро делиться» (работа), а не
  «хочу кнопку „Поделиться“» (решение).

## Чего не знаем

- Реальных интервью не было — сказано явно.
- Источник каждого job story: бриф / гипотеза / модельный респондент.
