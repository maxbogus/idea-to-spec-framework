# Regional checklist: 152-ФЗ (Россия)

> Справочный чек-лист, не артефакт прогона. Роль читает его, когда контур
> попадает под 152-ФЗ. Источник правды по стандартам — `standards-mapping.md`.

## Триггер

Применяется, если: обработка ПДн граждан РФ, данные хранятся или
обрабатываются в России.

## Данные и локализация

- [ ] Класс данных указан: ПДн / специальная категория / иные
- [ ] Цель обработки и правовое основание названы (ст. 5)
- [ ] Перечень ПДн минимизирован (ст. 5)
- [ ] Срок хранения определён и записан в `spec.md §6`
- [ ] Порядок уничтожения при достижении цели / отзыве согласия (ст. 19)
- [ ] Data residency: хранение на территории РФ

## Трансграничная передача

- [ ] Трансграничная передача ПДн зафиксирована или её отсутствие обосновано
- [ ] Если есть — требование уведомления РКН (ст. 12)
- [ ] Если контур трансграничный — вопрос о residency обязателен, даже в `auto`

## Безопасность

- [ ] Уровень защищённости ПДн определён (ПЗ-1 … ПЗ-4) — или зафиксировано,
      что уровень не определён (это допущение)
- [ ] Меры защиты по уровню перечислены
- [ ] Классификация данных: публичные / внутренние / конфиденциальные / ПДн
- [ ] Шифрование при передаче и при хранении

## Импортозамещение

- [ ] Стек из реестра отечественного ПО (для государственных и
      регулируемых проектов)
- [ ] СУБД: Postgres Pro / Astra Linux и альтернативы
- [ ] СКЗИ: КриптоПро или сертифицированные аналоги — если нужны
- [ ] ОС: если развёртывание в контуре госорганов
