# Чеклисты гейтов — рабочий справочник оркестратора


> Этот файл **не подключается к запросу модели**: оркестратор
> сверяется с чек-листами при проверке гейта, но не отвечает ими.
> Причина измерена на eval-прогоне (qwen2.5:7b): когда чек-листы
> были частью промпта, модель отвечала чек-листом вместо JSON
> ответа роли (`problemStatement`, `successMetric` вместо `mode`,
> `stage`, `completeness`). Файл — источник правды для человека и
> для `scripts/check-sync.sh`.

## Чеклист BA-gate

- [ ] problem statement сформулирован
- [ ] success metric измерим
- [ ] персоны и контур определены
- [ ] JTBD (работы) сформулированы и связаны с персонами
- [ ] JTBD связаны с success metric (через Product Manager)
- [ ] scope разделён: MVP (must-have) и полный scope (MoSCoW)
- [ ] домены и тарифы названы
- [ ] ограничения зафиксированы
- [ ] открытые вопросы выписаны

## Чеклист SA-gate

- [ ] use cases описаны
- [ ] функциональные требования перечислены
- [ ] нефункциональные требования перечислены
- [ ] интеграции названы
- [ ] данные и безопасность учтены
- [ ] acceptance criteria в формате BDD (Given/When/Then)
- [ ] для `risk: high` проведён STRIDE threat modeling
- [ ] NFR включает accessibility (WCAG 2.1 AA минимум)
- [ ] у каждого NFR есть мера, порог и метод проверки (или маркер
      `[не измеримо]`)
- [ ] у каждого FR есть негативный критерий приёмки (BDD)
- [ ] блок регуляторных требований заполнен

### Чек-лист безопасности (для high-risk доменов)

- [ ] OWASP Top 10 проверен
- [ ] STRIDE threat model построен
- [ ] классификация данных выполнена (public / internal / confidential / restricted)
- [ ] шифрование при хранении и передаче подтверждено

## Чеклист Spec-gate

- [ ] спецификация полна
- [ ] traceability matrix намечена: связь BR → FR заполнена; задачи `T-*` и
      статусы покрытия добавляет Plan (этап идёт после этого гейта — не
      требовать их здесь, иначе гейт не проходим по построению)
- [ ] risk register заполнен
- [ ] human oversight plan намечен
- [ ] fact-check прогнан, `hallucination-log.md` заполнен
- [ ] requirements-critic прогнан, расхождения зафиксированы и не сглажены
- [ ] все допущения помечены как гипотезы
- [ ] требования с `risk: high` имеют threat model
- [ ] ADR имеют статус, минимум две альтернативы и последствия
- [ ] региональные ограничения отражены (152-ФЗ / GDPR / PIPL / HIPAA)
