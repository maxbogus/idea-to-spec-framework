# Гайд оркестратора — справочник

> **Не подключается к запросу модели.** Причина измерена на eval-прогоне:
> когда гайд был частью промпта оркестратора, модель отвечала по гайду, а
> не по формату своей роли — подставляла чужие ключи вместо полей ответа.
> С гайдом в запросе — 0 из 5 кейсов оркестратора, без него — все пять с
> полным набором полей.
>
> Рабочие части (триггеры режима, критерии выбора режима) перенесены в
> `prompts/orchestrator.md` — в промпте роли. Чек-листы гейтов — в
> `prompts/gate-checklists.md`. Формат вопроса — тоже в промпте роли.
> Здесь остаётся справка для человека и агента.

## Триггеры режима

Режим выбирается **до** начала прогона, с учётом домена идеи:

- Идея про **медицину, финансы, детей, государственные услуги** →
  режим `auto` **запрещён**. Только `chat` или `hybrid`: в этих доменах
  цена ошибки (HIPAA, PCI DSS, COPPA, 152-ФЗ) выше стоимости уточнений.
  Если пользователь всё равно просит `auto` — предупреди и предложи
  `hybrid`.
- Идея с **трансграничным контуром** → обязательный вопрос о data
  residency (GDPR / PIPL / 152-ФЗ), даже в `auto`.
- Идея с **высоким риском для пользователя** (здоровье, деньги,
  безопасность) → `hybrid` как минимум.

Остальные случаи: `auto` допустим, если нет развилок, меняющих решение.

## Критерии выбора режима

- `auto` — низкая неопределённость, нужен черновик, развилок нет; всё
  неизвестное → допущение с пометкой.
- `chat` — есть 1–3 развилки, которые меняют решение (контур, платежи,
  интеграции); без ответа придётся угадывать.
- `hybrid` — по умолчанию: вопросы только на критичных развилках.

**Критерий остановки диалога:** ответ перестал менять следующий шаг или
снижать риск — прекращаем спрашивать и фиксируем допущение.

## Формат вопроса (chat / hybrid)

Каждый вопрос задаётся тремя блоками:

1. **Вопрос** — конкретный, меняющий следующий шаг.
2. **Зачем я это спрашиваю** — 2–4 предложения: что этим закрываем,
   какой риск снижаем, что появится на выходе.
3. **Термины** — расшифровка терминов из вопроса (формулировки — из
   «Глоссария терминов» ниже).

Правило действует для любого вопроса, включая стартовый (выбор режима).
